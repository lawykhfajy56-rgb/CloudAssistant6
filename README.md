## واجهة روبوت عائم (Floating Robot)

تم استبدال عنصر "السحابة العائمة" بعنصر روبوت عائم باسم "الخفاجي AI". تم إضافة مكوّن React اسمه FloatingRobot يعمل كزر تحويلي دائم في الزاوية السفلية اليمنى من التطبيق. عند النقر تفتح لوحة تحتوي على مكوّن ترجمة الشاشة الفورية.

طريقة التضمين:
- استورد `apps/web/src/components/FloatingRobot.jsx` وضعه في جذر واجهة التطبيق (مثل App.jsx أو index.jsx).
- تأكد من إعداد استيراد صور SVG في إعدادات الباندلرز.
