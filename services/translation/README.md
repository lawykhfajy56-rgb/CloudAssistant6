# خدمة ترجمة الشاشة الفورية (Screen Translation)

هذه الوثيقة تشرح تصميم المكوّن والخدمة التي توفر ترجمة شاشة فورية داخل تطبيق "الخفاجي AI" (CloudAssistant6).

الهدف
- أخذ لقطة شاشة (أو جزء من الشاشة) داخل الواجهة، استخراج النص (OCR)، ثم ترجمة النص إلى لغة الهدف وعرضه للمستخدم فورًا.
- أن تعمل كميزة داخل نفس التطبيق الحالي (لا تطبيق منفصل).

مكوّنات النظام
1. Frontend component (مثلاً React) يقوم بـ:
   - أخذ لقطة للشاشة أو عنصر DOM باستخدام html2canvas أو Capture API.
   - إرسال الصورة إلى OCR (Tesseract.js) أو إرسالها إلى خدمة OCR خارجية.
   - إرسال النص الناتج إلى مزود ترجمة (Google Translate API، DeepL، أو أي خدمة REST).
   - عرض الترجمة على شاشة المستخدم (overlay) مع وضعية قابلة للغلق.

2. Backend (اختياري):
   - يُفضّل تمرير طلبات الترجمة عن طريق خادم وسيط (proxy) لحماية مفاتيح API وللقيام بمعالجة إضافية (تجميع، حدود معدل).
   - يمكن أن يُنشأ endpoint بسيط: POST /api/translate { image_base64 | text, target_lang }

المتطلبات
- مفاتيح API للمترجم (إن استُخدمت خدمات مدفوعة).
- حزمة Tesseract.js أو خدمة OCR مستقلة.
- html2canvas لالتقاط العناصر DOM.

متغيرات بيئة مقترحة
- TRANSLATION_PROVIDER (google|deepl|custom)
- TRANSLATION_API_KEY
- OCR_PROVIDER (tesseract|custom)
- TARGET_LANGUAGE (مثلاً: ar, en, fr)

مثال سهل للتشغيل المحلي
- تثبيت الحزم في واجهة React:
  npm install html2canvas tesseract.js axios

- استدعاء endpoint الترجمة من المكوّن الأمامي أو مباشرةً من البراوزر إن كنت تستخدم مفاتيح عمومية (غير موصى به).

الأمان والخصوصية
- يُنصح بإرسال الصور أو النصوص الحساسة عبر خادم وسطي مشفّر.
- توفير خيار لمستخدم لحذف لقطات الشاشة بعد المعالجة.
